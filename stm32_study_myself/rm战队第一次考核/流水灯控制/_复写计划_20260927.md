## 5. "灯不亮"时的定位顺序（固定套路，不许猜）

```
RCC 时钟开了没
  → 引脚模式对不对（Out_PP / AF_PP / IPU）
    → 定时器参数（PSC / ARR / CCR）
      → 通道使能（CCER）
        → 主循环真的跑到这一行了吗
          → Watch 里那个变量到底是多少
```

**每次只改一个变量、只测一件事。** 一次改三处 = 你永远不知道是哪一处救的（这是最容易毁掉学习效率的习惯）。
