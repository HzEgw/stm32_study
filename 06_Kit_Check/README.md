# 06_Kit_Check —— 套件到货验收工具（提前备好）

> **什么时候用**：平衡车/电机套件**到货当天**（预计 W3 前后）。30 分钟分清
> "板子/电机/编码器到底有没有坏"，避免后面调 PID 时被硬件问题带偏。
>
> **为什么提前写好**：验收工具属于"等着用的工具"，不该等到货那天再写代码。

---

## 1. 它替你做什么

上电后自动跑 **一键自检**，6 项逐个给结论（串口 115200 打印 + Keil Watch 看 `g_kit_pass[]`）：

| # | 自检项 | 判定方式 | 需要人配合吗 |
|---|---|---|---|
| 1 | **LED** | 闪 3 次 | 人眼确认 |
| 2 | **按键** | 3 秒内按一下 | 按一下 |
| 3 | **I2C 总线 / IMU** | 扫描 0x08~0x77，看有没有 0x68（MPU6050）/ 0x3C（OLED） | 不需要 |
| 4 | **编码器 ×2** | 3 秒内手转两个轮子，看计数增量是否非 0 | 转轮子 |
| 5 | **电机 ×2 + 转向** | 每个电机正转 1s → 反转 1s，**用编码器增量自动判断转向对不对** | 不需要（会自己转） |
| 6 | **电池电压** | 读 ADC 并换算成 mV，判断是否在 9~14V 之间 | 不需要 |

自检结束后进入**常规模式**：每 500ms 打印两轮计数/转速/电池电压；按按键切换电机1 正转/停。

## 2. 接线（**默认映射**，到货后按丝印核对并改 `kit_config.h`）

| 功能 | 引脚 | 外设 | 备注 |
|---|---|---|---|
| 电机1 PWM / 方向 | **PA0 / PA1** | TIM2_CH1 + GPIO | 双 PWM 驱动的两条输入 |
| 电机2 PWM / 方向 | **PA2 / PA3** | TIM2_CH3 + GPIO | 同上 |
| 编码器1 A / B | **PA6 / PA7** | TIM3 编码器模式 | 硬件 4 倍频 |
| 编码器2 A / B | **PB6 / PB7** | TIM4 编码器模式 | 同上 |
| IMU（只扫描） | **PB10 / PB11** | I2C2 | 复用开漏，需上拉 |
| 电池电压 | **PA4** | ADC1_IN4 | 分压后接入 |
| LED | **PC13** | GPIO | 低电平点亮（`KIT_LED_ACTIVE_LOW`） |
| 按键 | **PA5** | GPIO 上拉输入 | 另一端接 GND |
| 串口打印 | **PA9 / PA10** | USART1 | 115200 8N1（USB-TTL） |

⚠️ **安全三条**：
1. 驱动板电源地与 STM32 的 **GND 必须共地**；
2. **12V 只能进驱动板 VM**，绝不能进 STM32 板；
3. 第一次上电先用万用表量驱动板逻辑供电（3.3V 还是 5V），再决定信号接法。

## 6. 常见问题

| 现象 | 原因与解决 |
|---|---|
| 串口全是乱码 | 波特率不是 115200 / 没共地 / TX-RX 接反（PA9 接 USB-TTL 的 RX） |
| 自检第 3 项扫不到任何器件 | I2C 没上拉（PB10/PB11 需 4.7k）或 IMU 挂在**另一条** I2C 上（那就改 `kit_config.h` 用 I2C1/PB6-PB7，并把编码器2 挪到别的定时器） |
| 编码器增量恒为 0 | ① 编码器供电（3.3V/5V）没接 ② A/B 接错脚 ③ `KIT_ENC1/2_*_PIN` 与实物不符 |
| 编码器增量方向与预期相反 | 交换 A/B 两线，或把该通道的 `TIM_ICPolarity_Rising` 改成 `Falling` |
| 电机不转 | ① 驱动板 STBY/EN 没拉高 ② 电机电源没接 ③ 方向脚/ PWM 脚接错 |
| 电机转但正反转都同向 | 双 PWM 驱动板的两个输入必须**互补**（本工程用"PWM + 方向脚"法，若你的板要求双 PWM，见 `kit_check.c` 注释改法） |
| 电池电压偏高/偏低固定倍数 | 分压系数错 → 改 `KIT_ADC_DIV_NUM / KIT_ADC_DIV_DEN` |
| 一上电电机就狂转 | 危险！立刻断电 —— 通常是把驱动板 STBY 悬空或 PWM 脚接成了电源脚 |

## 7. 到货后**只需要改两个地方**

1. **`HARDWARE\kit_config.h`**：引脚映射（按丝印）+ 电机/编码器/轮径/分压参数；
2. 若板上有 **OLED/无按键/无 LED**：把对应自检项在 `kit_check.c` 里注释掉即可（不影响其他项）。

## 8. 做完验收之后

- 验收数据贴进 `成长路线\01_FishBot硬件清点表.md` 与 `02_…` 第 8 节的"实读值"表；
- 紧接着 **W3 的直立环 PID**：编码器（本工程已验证）+ MPU6050（`05_I2C_MPU6050`/`_Reg`）→ PID 输出 PWM（本工程的 `Kit_MotorSet`）；
- ⚠️ 注意：**平衡车的轮径/减速比与鱼香小车不同**，PID 参数不能照抄，必须自己整定。
