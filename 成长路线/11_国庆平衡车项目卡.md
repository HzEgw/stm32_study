## 4. 规格卡（G1 / G2 · 一页照抄 `05` §9.5 体例）

### 4.1 G1 规格卡 · 双电机开环
| 项 | 目标值 | **怎么算 / 怎么测** | 判据 |
|---|---|---|---|
| PWM 频率 | **5 kHz**（与官方双 PWM 对齐） | `f = 72MHz/((PSC+1)(ARR+1))` → 优先 **`PSC=14 / ARR=959`**（5000.0 Hz） | Watch `g_tim3_freq` = 5000±3 |
| 通道 / 引脚 | **TIM3 `CH1~CH4` → PA6/PA7/PB0/PB1** | `PA6/PA7` = 电机 A 的两路，`PB0/PB1` = 电机 B 的两路 | 示波器四路同屏 |
| 方向定义 | 正转 = `A=占空比, B=0`；反转 = `A=0, B=占空比` | **写进 `README` 一张表**（不许凭记忆） | `README` 有那张表 |
| 转速表 | 至少 **4 个占空比点**（如 20/40/60/80%） | 编码器读数 → rpm（见 G2 换算） | `docs/data` 里一张 csv |
| 保护 | 起始占空比 **≤30%**，电机**架空** | 堵转电流大，先架空 | 照片/视频里电机离地 |

**常见坑（按历史错误预填）**：① `PSC/ARR` **没减 1**（09-21 实际 988.7 Hz，不是 1 kHz）；
② 引脚配成 `AF_PP` 后**改回普通输出没重配**（09-25 坑②）；③ 方向脚与 PWM 脚**初始化职责**没写清（09-25 坑②同源）。

### 4.2 G2 规格卡 · 编码器测速
| 项 | 目标值 | 怎么测 | 判据 |
|---|---|---|---|
| 一圈计数 `CPR` | **实测**（§1 表那格） | 手转输出轮**整一圈**，读 `Kit_EncoderGet()` 增量 | Watch 值 = §1 表值 |
| 转速换算 | `rpm = Δ计数 ÷ CPR × (60 ÷ Δt)` | **先把式子写进 `README`，再写代码**（`09` §3 动作 4） | 与秒表手测 **±5%** 内 |
| 方向符号 | 正转为正、反转为负 | 正反转各测一次 | 两次符号相反 |
| 采样节拍 | 100 ms（定时器中断里只"取数 + 置标志"） | `README` §4 第 4 条（中断只取数） | 中断里无计算、无打印 |

**常见坑**：① 把"捕获满量程"当编码器量程（09-23 `ARR=65536-1` 的翻版）；② 在中断里做浮点除法 + 打印；
③ 单位换算时 `×60` 与 `÷Δt` 顺序写错 → 数值差 3600 倍（**先量纲，再算数**）。

## 6. 安全红线与停手条件（**硬件部分，比代码更重要**）

1. **先量电压链，再接线**：电池 → `TB6612` 的 `VM` / `VCC` → 板载 `5V` / `3.3V` → 各模块。写一张**电压链表**（`01` §4.1 教训：12V 不能直进开发板）。
2. **加开关 + 保险丝**；**换电机线前先断 `VM`**（带电插拔会烧 `TB6612`）。
3. **电机架空再上电**；起始占空比 ≤30%；**禁止手按车轮**做堵转测试。
4. **单点接地/共地检查**（开发板 GND ↔ 驱动板 GND ↔ 电源 GND 必须共地）。
5. **23:00 前收工**；每天最后 30 min 收拾线材（防第二天断线误判成"代码坏了"）。
6. **停手条件**：某里程碑 **2 天无进展** → 按 `00` §16.6 "平衡车卡死"预案执行（退回"编码器 + 单环"或跳过 G4）。
