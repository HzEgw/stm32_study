# 13 · 成果转化路线（**P-02 卡**）：小车 → 专利 / 论文 / 大创 / 竞赛

> **来源**：用户 2026-09-25 提问 —— 「我的小车项目能不能产出一个专利或者论文或者任何成果导向的东西，只能是实力证明吗？」
> **依据（原文级）**：`附件1 机电工程学院推免生推荐工作实施细则`（湘农机电〔2025〕18 号）＋ 2027 年通知正文（两者均已逐字解码核对）
> **适用届别**：我是 **2025 级四年制 → 2029 届**（申报 2028-09 上旬，材料认定截止 **2028-09-01**）；学院《实施细则》逐年修订，**以我申报当年文件为准**
> **定位（一句话）**：**它不是"只能当实力证明"——它就是成果的原料；要补的不是技术，是"注册主体（指导教师）+ 投递口径（刊物/赛事级别）"两件事。**
>
> ### 四条红线（照旧先读）
> 1. **只认"授权发明专利"，不认实用新型 / 外观 / 软著**（原文见 §1）——别把"申了专利"当成"能加分"。
> 2. **普刊论文 0 分**：细则只认 Ⅰ/Ⅱ 区 SCI、中文 TOP、其他 **EI/SCI/CSCD 收录**（需检索报告）＋《农业工程与装备》（限 1 篇 2 分）。**花钱发普刊 = 白花**。
> 3. **套件不算自主成果**：评审（专家审核小组）要"排除…有名无实"、要"评价创新质量和个人贡献"，第一句必是"这不是买来就能跑吗"（与 `11` §红线 4 同源）。
> 4. **署名口径是硬的**：论文 = **湖南农业大学第一署名单位、第一作者**；专利 = **湖南农业大学为唯一专利权人、本人第一发明人**。**不要署职院**。

> **能产出成果，且不止一项；但"专利 + 论文"不是最优通道 —— 你的最优组合是「大创主持（省级/国家级）+ 挑战杯/智能农业装备赛事」，专利与论文作为它们的"副产物"顺手产出。**

## 4. 最小成果包：**「一鱼四吃」方案（P-02 的技术内核）**

> **前提**：我的定位本来就是「**电控 ↔ ROS2 之间的桥**」（`README` §1），而我已经有**两套可对比的实现**：
> **A = 自写 `uart_bridge`（0xAA55 帧协议）** vs **B = micro-ROS 原生节点**（W6~W7 计划）。

| 项 | 内容 |
|---|---|
| **实验名** | 「MCU↔ROS2 通信的**两种实现**对比：手写帧桥 vs micro-ROS 原生节点」 |
| **自变量** | 波特率阶梯 **115200 / 230400 / 460800 / 921600**（每档 10 min × 3 次） |
| **因变量** | ① **端到端时延**（MCU 打时间戳 → ROS2 收到 / `ros2 topic delay`）；② **丢帧率 + 校验错率**（`uart_bridge` 已有 `bad_sum_` 计数）；③ **CPU 占用**（`top` / `ros2 topic hz`）；④ **代码量 + RAM/Flash**（Flash 占用用 Keil map 文件）；⑤ **可维护性**（改动一处的行数） |
| **规格卡先行** | 采样率 / 帧长 / 每档时长 / 判据阈值**全部先写进 README 再跑**（`09` §3 动作 1；`10` 卡模板） |
| **四处产出** | ① **挑战杯/互联网+ 作品说明**的核心章（有对比、有数据、有结论）；② **大创结题报告**核心数据；③ **论文**（§3.4 ②）；④ **发明专利**（"一种 MCU–上位机通信方法及装置"，含**自适应重传 / 丢帧诊断**） |
| **为什么选它** | 唯一**只靠现有硬件 + 已有代码**就能产出**定量对比数据**的方向；且**顺带解决 micro-ROS 学习**（本来就在 W6~W7 的计划里）→ **不额外占时间** |

> ⚠️ **反向提醒**：**不要**把"我做了个平衡车/小车"本身当成果 —— 那是**平台**，不是**成果**。成果 = **别人没做过的对比/方法/结构**。
