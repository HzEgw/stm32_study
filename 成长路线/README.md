### 3.1 双系统（Windows + Ubuntu）文件布局 —— 重要

**铁律：ROS2 的编译工作空间必须放在 Linux 的 ext4 上，绝不在 NTFS 上 `colcon build`**
（NTFS 的权限位/大小写/软链接/性能都会出问题，git 仓库放 NTFS 也会报权限警告）。

| 内容 | 位置 | 说明 |
|---|---|---|
| STM32 工程 / Keil / 笔记 / 计划 | **Windows D:（现工作区）** | Keil 只能在 Windows |
| ROS2 **包源码** | 工作区里做"源码仓"（如 `ros2_ws_src\<包名>`） | 源码可跨系统，**编译产物不行** |
| ROS2 编译与运行 | **Linux `~/ros2_ws`（ext4）** | `git pull` → `colcon build` 都在这边 |
| 跨系统同步手段 | **git**（W1 建仓库） | Windows 提交 → Linux 拉取；`.gitignore` 排除 `build/ install/ log/` |
| 只想在 Linux 里"看"笔记 | 只读挂载 NTFS（`/etc/fstab` 加 `ntfs3` 或 `ntfs-3g`，带 `ro`） | 用来看，不要用来编译 |

**GitHub 仓库分工（3 个，2026-09-19 定）**：`stm32_study`（本工作区，含**自研** `ros2_ws_src/uart_bridge`）·
`ros2_study`（《动手学ROS2》**教程练习** chapt1~10，**非自研**，README 需注明出处）·
`stm32-ros2-lidar-car`（**比赛作品库**，W5 后建）。详见 `04_Ubuntu侧开工清单.md` §0.1。

Linux 端典型流程：
```bash
cd ~/ros2_ws/src
git clone <仓库地址>            # 或 git pull
cd ~/ros2_ws && colcon build --symlink-install
source install/setup.bash
```

## 4. 代码风格约定（新代码必须遵守）

1. **每个主题出两份**：标准库版 + 寄存器版，各自独立工程（不共享源码）；
2. **注释标注寄存器与位**：如 `TIM3->CCR1 = ccr;` / `/* -> TIM3->CCR1 = ccr */`，并说明位含义；
3. 每个工程带 `README.md`：文件清单、Keil 建工程步骤、Include Paths、Define、引脚表、**验证方法（没有 LED/串口也能验证）**、常见问题、标准库↔寄存器对照表；
4. 中断只做"取数 + 置标志"，计算放主循环；中断共享变量加 `volatile`；模块内部数据/函数用 `static`；
5. 验证优先用：Keil Watch 变量 + 万用表/示波器 + 把信息编码到 PWM 输出；
6. 所有代码进 git（W1 建仓库），参数放配置文件，不硬编码；
7. 引脚约定：避开 SWD（PA13/PA14）与串口（PA9/PA10）。
8. **换行符**：仓库统一存 **LF**（根目录 `.gitattributes` 已配好），Windows 工作区照旧 CRLF ——
   **不用再手动设 `autocrlf`**；改过 `.gitattributes` 后跑一次 `git add --renormalize .` 即可。
   目的：Linux 侧 `colcon build` / `.sh` 脚本不会因 CRLF 报 `bad interpreter` 之类的怪错。
9. **笔记是"草稿"，不是成品**（2026-09-20 新增）：AI 提炼的笔记一律**留空白** ——
   每篇末尾必须有「**我的补充**」「**我的疑问**」两个空区块；**本人过一遍并动手补写**之后才算"学过"。
   > 理由：AI 帮你把话说清楚了，但**知识没长在你手上**。留白 + 手写批注，是把"看懂"变成"会"的唯一办法。
   > 配套：周日复盘时间由 30min → **50min**，其中**至少 20min 用来读笔记 + 补空白**（见 `03` §1/§3/§6）。
10. **git 全部本人手敲**（2026-09-20 起生效）：AI 只提供命令 + **只读**的事后验证，
    **不代跑** `init / add / commit / push / branch / mv`。
    > 理由：简历与答辩里"我用了版本管理"要经得起追问 —— 只有手上敲过、踩过坑，才是你的。
