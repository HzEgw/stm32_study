## 3. 运动学参数推算（含公式，实测后回填）

**✅ 已确认（2026-09-19 第二轮，来源：官方固件源码默认值 —— 见 `02_FishBot官方固件参数与STM32移植映射.md`）**

| 参数 | 值 | 说明 |
|---|---|---|
| 轮径 `D` | **65 mm** | 与发货清单一致 |
| **轮距 `L`** | **172.75 mm** | 官方固件 `KINEMATIC_WHEEL_DISTANCE` 默认值（odom 必需）|
| 减速比 `i` | **40.5** | 官方固件默认（旧版固件是 46）|
| 编码器脉冲比 | **44** = **11 线 × 4 倍频** | 电机转一圈的脉冲数 |
| **每输出轴一圈计数 `N`** | **1782** = 40.5 × 44 | 编码器接口模式同样是 4 倍频，**可直接照搬** |
| **里程分辨率** | **0.114592 mm/count** | = 204.2035 / 1782 |

> ⚠️ **必须实车确认**：旧固件示例里是 `46 / 42 / 轮距150`，说明这几颗数**随机型批次变化**。
> 确认方法：跑官方固件用 ROS2 读配置服务，或手转输出轮一圈读 `03_Encoder` 的计数（应为 1782）。

固定公式（写进代码时用这些）：

```
C = π × D = π × 65 = 204.2035 mm
N = 脉冲比 × 减速比 = 44 × 40.5 = 1782
per_pulse_distance = C / N = 0.114592 mm/count
转速 rpm = Δcount / N × (60000 / 采样周期ms)
线速度 v = Δcount × per_pulse_distance × 1e6 / dt(µs)   [mm/s] → /1000 得 m/s
里程     s = Δcount × per_pulse_distance                  [mm]
```

**最高速度估算**（370 12V 减速电机，1:30 时空载约 250~350 rpm）：

| 转速 | 线速度 |
|---|---|
| 200 rpm | 0.68 m/s |
| 300 rpm | 1.02 m/s |

> 巡检/避障小车 0.3~0.8 m/s 足够 —— **说明这套底盘不必换电机**（P2 的 M3508 升级可以继续搁置）。

**差速运动学**（对应 ROS2 `diff_drive_controller` / Nav2）：

```
v = (v_R + v_L) / 2
ω = (v_R − v_L) / L            (L = 轮距，待实测)
v_L = v − ω·L/2 ,  v_R = v + ω·L/2
```

需要回填进上位机的参数：`wheel_separation`(=L)、`wheel_radius`(=0.0325 m)、`counts_per_rev`(=N)。

## 4. 供电与接口预算（改造 STM32F407 下位机时用）

### 4.1 供电链（⚠️ 最容易烧板子的地方）

```
12V 电池组 ──┬─→ 电机驱动（板载 TB6612/DRV8833 之类，待看丝印）→ 2×370 电机
             └─→ 【12V→5V DC-DC ≥3A】─→ F407 开发板 5V 脚 ─→ 板载 3.3V LDO ─→ 传感器
```

| 规则 | 说明 |
|---|---|
| **12V 绝不直接进开发板** | F407/F103 板的 5V 脚最多耐受 5.5V，直连 12V 立即烧 |
| 必须补买 | **12V→5V 3A 以上 DC-DC 降压模块 ×2**（约 15~30 元/个，备一个），或选"宽压 12V 输入的电机驱动板 + 5V 输出" |
| 传感器取电 | 3.3V 从开发板取；**编码器供电先实测是 3.3V 还是 5V 再接线** |
| 测电压 | 用 ADC 分压测电池电压（顺路学 ADC，门槛低、加分行） |
| 功耗估算 | 主控+雷达+传感器 ≈ 0.4~0.6A，两电机堵转可达数 A；2800mAh 电池实测续航预计 **40~70 min** |

### 4.2 F407 侧引脚/外设预算（一版初步方案，到货前再定）

| 外设 | 数量 | STM32 资源 | 学到的东西 |
|---|---|---|---|
| 电机 PWM ×2 | 2 | TIM1_CH1 / TIM1_CH2（或 TIM2/TIM4） | 高级定时器、互补输出（可扩展死区） |
| 电机方向 ×2 | 2 | 普通 GPIO（或再 2 路 PWM 做"双 PWM"驱动） | — |
| 编码器 ×2 | 2 路 | **TIM3 CH1/CH2 + TIM4 CH1/CH2**（编码器接口模式，硬件 4 倍频） | 已在 `03_Encoder` 练过 |
| 雷达 MiniV1 | 1 | UART + **DMA 接收**（点云帧长、波特率高） | UART/DMA、帧解析 |
| MPU6050 | 1 | I2C1（PB6/PB7） | 已在 `05_I2C_MPU6050` 练过 |
| OLED 0.96" | 1 | **I2C1 共用**（地址 0x3C ≠ 0x68） | **I2C 多设备 + 地址区分** |
| SR04 超声波 | 1 | TRIG = GPIO 输出；ECHO = TIM 输入捕获 | `02_Input_Capture` 实战（⚠️ ECHO 5V 需分压：1k + 2k） |
| 电池电压 | 1 | ADC 通道 | ADC |

## 5. 可以今天就做的实测（按顺序，30~60 分钟）

> 工具：卷尺/卡尺、万用表、示波器（可选）、手机（拍照归档到 `docs/media/`，命名 `20260919_xxx.jpg`）

### A. 先"不改硬件"摸底（用官方固件，最安全）
1. 小车通电 + 连上官方 App/WiFi，确认雷达转起来、能遥控；
2. 在 PC 上（Ubuntu）看 **ROS2 话题与参数**，把下面这张表填满：
   - `ros2 node list` / `ros2 topic list` / `ros2 topic info <scan话题>`
   - `ros2 topic hz <scan话题>` → **扫描频率**（期望 5~12 Hz）
   - `ros2 topic echo --once <scan话题>` → 记 `angle_min/angle_max/angle_increment/range_min/range_max/scan_time/frame_id`
   - `ros2 topic hz <odom话题>` 与 `ros2 param list <下位机节点>`
   - 遥控拉到最快时 `ros2 topic echo <cmd_vel话题>` → 记 `linear.x` 上限 → **反推电机最高转速**
3. 这些数字 = 将来 STM32 固件**必须复现的验收标准**（对比实验的基线数据，直接进挑战杯报告）。

- [ ] 轮径实测（含胎）：______ mm（清单说 65）

## 6. 清点带来的 6 个结论（对计划的实际影响）

1. **雷达不用买** ✅ —— MiniV1 全新，够用于避障+建图。原计划"P1 激光雷达 400~900 元（若现有雷达不够）"**降级为条件触发**：只有实测发现角分辨率/量程不满足农业场景需求才买。省下的钱给车载计算/备件。
   - 📌 **链路认知修正（官方源码）**：雷达转接板（`fishbot-laser-control`，**ESP8266**）只是"**UART → WiFi 透传**"，可配 `laser_baud`（波特率）与 `motor_speed`（转速）；**协议解析在上位机**。所以"雷达协议"只影响 **STM32 直连雷达**这条可选路线，不影响现有工作流。
2. **车载计算优先树莓派** —— 清单第 9 项"X2 雷达底板（**树莓派底板**）"说明顶层板**预留了树莓派安装位**：装树莓派 5/4 不用 3D 打印转接件，比 NUC 更省事。建议 12 月第 2 批把"二手 NUC"改成**树莓派 5（8G）+ 散热壳**优先（约 700~900 元，还能上 Ubuntu 24.04 + ROS2）。
3. **F407 是唯一"必须买"的大件** —— 底盘/雷达/电机/电池/OLED/超声波全都齐了，11 月第 1 批预算里 F407 的优先级没有任何悬念。
4. **必须补买 12V→5V DC-DC（≥3A）** —— 原采购表只写"DC-DC 电源模块"太泛，规格要写清楚（见 4.1），否则 F407 上电第一天就可能烧板。
5. **白捡两个练习对象** —— SR04 超声波 = `02_Input_Capture` 的实战（⚠️ 5V 分压）；OLED = 与 MPU6050 共挂 I2C1 的**多设备练习**（0x3C / 0x68）。这两项都不用额外花钱。
6. **运动学只差两个数** —— 轮径 65 mm 已确定，只剩**减速比/PPR**（第 5 节 C 步）和**轮距**（第 5 节 B 步），一小时内可全部测完，**W1 就能把"参数清点"这一项真正打完勾**。
