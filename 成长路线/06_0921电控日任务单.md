### ⚠️ 三个坑（第 1 个正是你在 `6-2` 里踩过的）

1. **`GPIO_Pin_14` ≠ `GPIO_PinSource14` ≠ `EXTI_Line14`**

   - `GPIO_PinSource14`（0x0E）→ 给 **`GPIO_EXTILineConfig()`** 用

3. **中断里必须清标志**（`EXTI_ClearITPendingBit`），否则出不来中断

### 寄存器速查（你要的"先讲清用了哪些寄存器"）

| 寄存器 | 作用 | 今天用到的位 |
|---|---|---|
| `RCC->APB1ENR` | TIM3 时钟 | **bit1 TIM3EN** |
| `RCC->APB2ENR` | GPIO 时钟 | bit2 IOPAEN、bit3 IOPBEN |
| `GPIOA->CRL` | PA6/PA7 配置 | 每引脚 4 位：`[3:2]CNF=10 复用推挽` `[1:0]MODE=11 50MHz` → **0xB**；PA6=bit27:24、PA7=bit31:28 |
| `GPIOB->CRL` | PB0/PB1 配置 | PB0=bit3:0、PB1=bit7:4 → 都是 **0xB** |
| `TIM3->PSC` / `TIM3->ARR` | 预分频 / 周期 | `计数频率 = 72M/(PSC+1)`；`PWM频率 = 计数频率/(ARR+1)` |
| `TIM3->CCMR1` | CH1/CH2 模式 | `OC1M[6:4]=110`（PWM1）、`OC1PE`(bit3)=1；CH2 同理在 bit14:12 / bit11 |
| `TIM3->CCMR2` | **CH3/CH4 模式** | `OC3M[6:4]=110`、`OC3PE`(bit3)=1；CH4 在 bit14:12 / bit11 |
| `TIM3->CCER` | 输出使能/极性 | **CC1E=bit0、CC2E=bit4、CC3E=bit8、CC4E=bit12** |
| `TIM3->CCR1~CCR4` | 占空比 | 高电平时间 = `CCR` 个计数 |
| `TIM3->CR1` | 控制 | bit7 ARPE、bit0 CEN |
| `TIM3->EGR` | 事件 | bit0 UG（立刻装载） |

### ⚠️ 三个坑
1. **TIM3 是通用定时器** → 结构体里**不要**填 `TIM_OutputNState / TIM_OCIdleState / TIM_RepetitionCounter` 之外的高级字段（那是 TIM1/TIM8 才有的），填了不报错但没用

3. `TIM_SetCompare3/4` 才是 CH3/CH4 的 API（别全用 `SetCompare1`）
