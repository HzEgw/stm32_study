## 一句话总纲（记住这个就够了）

> **`static` 管"名字在哪个文件里存在"，`volatile` 管"每次都要真的去内存读写"，
> `const` 管"只读"，`extern` 管"这个符号定义在别的文件里"。**
> 它们都**不是**访问控制（C 里没有 private）。
