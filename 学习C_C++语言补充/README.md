## 怎么用这份笔记

1. **先看 `01`**：它是"为什么"——理解 C 的编译/链接模型，后面两个都是它的延伸；
2. 再按需查 `02`、`03`：它们是"怎么写"；
3. 复习时只看 `04` 的表格 + 自查清单，5 分钟就能过一遍。

## 一句话总纲（记住这个就够了）

> **`static` 管"名字在哪个文件里存在"，`volatile` 管"每次都要真的去内存读写"，
> `const` 管"只读"，`extern` 管"这个符号定义在别的文件里"。**
> 它们都**不是**访问控制（C 里没有 private）。
